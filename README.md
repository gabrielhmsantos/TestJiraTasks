# TestJiraTasks

Repositório com a **estrutura inicial Next.js** para desenvolvimento incremental da landing page (issue KAN-10).

## Início rápido

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Documentação

- [Setup do projeto, bootstrap e notas de ambiente](docs/project-setup.md)

O build gera site estático (`output: "export"`) na pasta `out/` após `npm run build`.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS v4, ESLint — conforme [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).
